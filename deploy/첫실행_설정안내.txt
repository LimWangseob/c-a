[쿠팡 애널리틱스] 새 PC 설치 안내 (무설정)
========================================

이 배포본은 "압축 풀고 → 설치.bat → 끝" 으로 됩니다. 설정 탭에 다시 입력할 것이 없습니다.

----------------------------------------
1) 압축 풀기
----------------------------------------
- 받은 zip(쿠팡애널리틱스_배포.zip)을 **바탕화면이나 문서 폴더**에 풉니다.
  (C:\Program Files 같은 쓰기 제한 폴더는 피하세요.)

----------------------------------------
2) 설치.bat 실행 (관리자 권한 권장)
----------------------------------------
- 풀린 '쿠팡애널리틱스' 폴더 안 '설치.bat' 을 우클릭 → "관리자 권한으로 실행".
- 설치.bat 이 한 번에 처리합니다:
   · 바탕화면·시작메뉴 바로가기 생성
   · 야간 무인 자동실행 등록(매일 18:00 시작 → 06:00 종료) — 물어보면 Y
   · **설정 자동 적용**: 구글시트 링크(관리대장·결과) + 네이버·OpenAI·구글SA 키를
     이 PC 전용 암호화(DPAPI)로 저장하고, 담겨온 평문 설정파일(_설정값.json)은 자동 삭제.

----------------------------------------
3) 실행
----------------------------------------
- 바탕화면 '쿠팡 애널리틱스' 바로가기 더블클릭 → 바로 사용(설정 입력 불필요).
- 또는 등록된 야간 무인 자동실행에 맡기기.

----------------------------------------
꼭 확인
----------------------------------------
- 이 PC에 **Google Chrome** 이 설치돼 있어야 합니다(정책상 실제 Chrome으로만 동작).
- 로그인/판매수집은 위치기반 2차인증 때문에 **사무실 환경**에서 잘 됩니다.
  낯선 환경(집·새 PC)에서는 뜨는 Chrome 창에서 직접 인증하세요.
- 계정 비밀번호는 관리대장의 '비밀번호' 컬럼에서 매 실행 자동 로드(별도 입력 없음).
- 재부팅 자동복구가 무인으로 동작하려면 Windows 설정>계정>로그인 옵션의
  "업데이트/다시 시작 후 자동 로그인 완료"를 켜 두세요.

----------------------------------------
⚠ 보안 (중요)
----------------------------------------
- 배포 zip 과 그 안의 '_설정값.json' 에는 **네이버·OpenAI·구글SA 키가 평문**으로 들어있습니다.
  · 외부 공유·이메일·클라우드 업로드 금지. 설치가 끝나면 zip 도 삭제하는 것이 안전합니다.
  · 설치.bat 이 정상 실행되면 _설정값.json 은 자동으로 지워집니다(남아있으면 직접 삭제).

----------------------------------------
설정이 자동 적용 안 됐을 때만 (수동)
----------------------------------------
- 설정 탭에서: ①입력 소스(관리대장 링크) ②네이버 API 키 ③OpenAI 키
  ④구글 서비스계정(SA) 키 파일 + 입력/출력 시트 링크 → [연결 확인].
