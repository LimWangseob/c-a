[쿠팡 애널리틱스] 새 PC 설치 안내 (무설정)
========================================

이 배포본은 "보안 제외 → 압축 풀고 → 설치.bat → 끝" 으로 됩니다. 설정 탭에 다시 입력할 것이 없습니다.

⚠⚠ 중요: 우리 프로그램(exe)은 Windows Defender 가 "오탐(가짜 위험)"으로 자동 삭제할 수 있습니다.
    실제 바이러스가 아니라, 프로그램에 코드서명이 없어 Defender 가 의심하는 것입니다(이름 끝 !ml = 오탐 표시).
    → 그래서 **압축을 풀기 전에** 아래 0)번을 먼저 하세요.

----------------------------------------
0) 보안 검사 제외 (압축 풀기 전에 · 관리자 권한) ★먼저★
----------------------------------------
- zip 을 받은 폴더에서 zip 안의 '0_먼저실행_보안제외.bat' 을 꺼내(또는 zip 을 한 번 풀어서)
  **마우스 오른쪽 → "관리자 권한으로 실행"**.
- 그러면 설치 폴더가 Defender 검사 제외에 등록돼 exe 가 삭제되지 않습니다.
- (이미 풀어서 exe 가 지워졌으면: 이 bat 을 먼저 실행한 뒤 zip 을 한 번 더 푸세요.)

----------------------------------------
1) 압축 풀기
----------------------------------------
- 받은 zip(쿠팡애널리틱스_배포.zip)을 **바탕화면이나 문서 폴더**에 풉니다.
  (C:\Program Files 같은 쓰기 제한 폴더는 피하세요.)
- 0)번 보안 제외를 먼저 했으면 이제 exe 가 삭제되지 않습니다.

----------------------------------------
2) 설치.bat 실행 (관리자 권한 권장)
----------------------------------------
- 풀린 '쿠팡애널리틱스' 폴더 안 '설치.bat' 을 우클릭 → "관리자 권한으로 실행".
- 설치.bat 이 한 번에 처리합니다:
   · 바탕화면·시작메뉴 바로가기 생성
   · 야간 무인 자동실행 등록(매일 18:00 시작 → 06:00 종료) — 물어보면 Y
   · **설정 자동 적용**: 노트북에서 검증한 설정(config.json = 구글시트 링크 4개[관리대장·결과·재고현황·
     원장]·입력소스·순위 간격·프록시 토글)과 노출순위 프록시 자격증명(proxies.txt)을 **그대로 복사**하고,
     네이버·OpenAI·구글SA 키는 이 PC 전용 암호화(DPAPI)로 저장 후 평문 설정파일(_설정값.json)은 자동 삭제.
     (설정 탭에 다시 입력할 것이 없습니다 — 노트북 설정이 그대로 넘어옵니다.)

----------------------------------------
3) 실행
----------------------------------------
- 바탕화면 '쿠팡 애널리틱스' 바로가기 더블클릭 → 바로 사용(설정 입력 불필요).
- 또는 등록된 야간 무인 자동실행에 맡기기.

----------------------------------------
꼭 확인
----------------------------------------
- 이 PC에 **Google Chrome** 이 설치돼 있어야 합니다(정책상 실제 Chrome으로만 동작).
- 로그인/판매수집은 위치기반 2차인증 때문에 **사무실 환경**에서 잘 됩니다.
  낯선 환경(집·새 PC)에서는 뜨는 Chrome 창에서 직접 인증하세요.
- 계정 비밀번호는 관리대장의 '비밀번호' 컬럼에서 매 실행 자동 로드(별도 입력 없음).
- 재부팅 자동복구가 무인으로 동작하려면 Windows 설정>계정>로그인 옵션의
  "업데이트/다시 시작 후 자동 로그인 완료"를 켜 두세요.

----------------------------------------
정산 자동 다운로드 (선택 · data\정산_계정목록.txt 필요)
----------------------------------------
- 정산 자동 다운로드는 **18:00 무인 실행의 ①판매수집이 끝나면 앱이 띄웁니다**(별도 예약작업 없음·2026-10-09).
  · 18:00 앱이 시작되면 이전에 떠 있던 앱 창과 정산 프로그램은 자동으로 종료되고 새로 시작합니다.
  · ②키워드·③순위가 도는 동안에도 정산은 계속 받고, **모든 정산 파일을 받으면 기록하고 스스로 종료**합니다.
  · 연속 실패·차단으로 멈추면 기록을 남기고 종료 → 다음 날 ①판매수집 뒤 이어서 받습니다.
  · 예전 설치의 '쿠팡애널리틱스_정산다운로드' 예약작업(로그온·08:00)은 18:00 앱이 자동으로 지웁니다.
  · 앱 '정산' 탭의 [정산 시작]/[정산 중지] 버튼으로도 켜고 끌 수 있고, 거기서 지금 상태(대기중/실행 계정/정산일/오류)를 봅니다.
- 이 정산 자동 다운로드는 **data\정산_계정목록.txt** 파일이 있어야 돕니다.
  · 형식(UTF-8 텍스트): 한 줄 = "계정ID  비번  대표자-사업자" (공백 또는 탭으로 구분).
  · 정산 대상은 관리대장보다 넓은 **위탁 계정 전부**라, 이 파일을 입력으로 씁니다.
  · ⚠ 비밀번호가 평문이라 **배포 zip 에는 들어있지 않습니다** — 이 PC 의 data 폴더에 소유자가 직접 넣으세요.
    (업데이트로 새 zip 을 덮어써도 data 폴더는 보존되니 한 번만 넣으면 됩니다.)
  · 읽은 비번은 이 PC 암호 저장소(DPAPI)에 암호화 저장되고 로그인에 씁니다. 기록·파일이름엔 비번을 쓰지 않습니다.
  · 파일이 없으면 정산 다운로드는 기록(output\정산\로그\)에 '정산 계정 파일 없음'을 남기고 그냥 종료합니다(오류 아님).
- 상태 확인(창이 없어 안 보일 때): 설치 폴더의 **'정산_상태확인.bat'** 더블클릭 → 지금 상태(대기중/작동중)·
  작업 등록 여부·프로세스 실행 여부·최신 상세 로그 끝부분을 한 화면에 보여 줍니다.
  · 자세한 기록은 output\정산\로그\ 폴더: _현재상태.txt(지금 상태)·실행_*.log(흐름)·처리기록_누적.csv(결과표·엑셀).
- 아무 때나 한 번 받기(사무실): 설치 폴더의 **'정산_지금실행.bat'** 더블클릭 → 정산 다운로드를 즉시 1회 실행
  (시간 제한 없이 끝까지 돎·18:00 야간 자동과 겹치면 앱이 쓰는 계정만 건너뜀). 2차인증은 뜨는 크롬 창에서 직접.

----------------------------------------
⚠ 보안 (중요)
----------------------------------------
- 배포 zip 과 그 안의 '_설정값.json'(네이버·OpenAI·구글SA 키) · '_씨앗\proxies.txt'(프록시 자격증명)에는
  **민감한 자격증명이 평문**으로 들어있습니다.
  · 외부 공유·이메일·클라우드 업로드 금지. 설치가 끝나면 zip 도 삭제하는 것이 안전합니다.
  · 설치.bat 이 정상 실행되면 _설정값.json 은 자동으로 지워집니다(남아있으면 직접 삭제).
  · proxies.txt 는 운용 PC 루트로 복사되어 계속 쓰입니다(프록시 동작에 필요 — 그 PC 안에서만 보관).

----------------------------------------
설정이 자동 적용 안 됐을 때만 (수동)
----------------------------------------
- 설정 탭에서: ①입력 소스(관리대장 링크) ②네이버 API 키 ③OpenAI 키
  ④구글 서비스계정(SA) 키 파일 + 입력/출력 시트 링크 → [연결 확인].
