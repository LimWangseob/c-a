[쿠팡 애널리틱스] 첫 실행 설정 안내
========================================

새 PC에서 처음 실행할 때 아래를 설정하세요.

⚠ API 키·비밀번호·구글시트 SA키는 "이 PC 전용"으로 암호화(DPAPI) 저장됩니다.
   다른 PC에서 쓰던 값은 복호화가 안 되므로, 새 PC에서 반드시 다시 입력해야 합니다(보안상 정상).

----------------------------------------
1) 실행
----------------------------------------
- 바탕화면의 '쿠팡 애널리틱스' 바로가기 더블클릭
  (바로가기가 없으면 폴더 안 '쿠팡애널리틱스.exe' 더블클릭)

----------------------------------------
2) 설정 탭에서 입력
----------------------------------------
① 입력 소스
   - 관리대장 구글시트 링크(기본) 또는 PC 엑셀 중 선택

② 네이버 검색광고 API 키        (필수)

③ OpenAI(ChatGPT) API 키        (키워드 AI에 필수 — 없으면 실행 중단)

④ 구글시트 연동
   - 서비스계정(SA) 키 파일 등록
   - 입력 시트 링크(관리대장)
   - 출력 시트 링크(결과)
   - [연결 확인] 버튼으로 정상 연결 확인

⑤ 비밀번호
   - 입력 엑셀/관리대장의 '비밀번호' 컬럼에서 자동 저장(별도 입력 불필요)

----------------------------------------
3) 실행
----------------------------------------
- '전체실행' 탭에서 수동 실행
- 또는 설치 시 등록한 야간 무인 자동실행(매일 18:00 시작 · 06:00 종료)

----------------------------------------
참고
----------------------------------------
- 결과 파일(쿠팡데이타분석_통계.xlsx)·로그·크롬 프로필은
  이 폴더 안 output\ , data\ 에 생성됩니다.
- 로그인/판매수집은 위치기반 2차인증 때문에 사무실 환경에서 잘 됩니다.
  낯선 환경(집·새 PC)에서는 뜨는 Chrome 창에서 직접 인증하세요.
- 이 PC에 Google Chrome이 설치돼 있어야 합니다(정책상 실제 Chrome으로만 동작).
- 설치·예약 관련 자세한 내용은 같은 폴더의 INSTALL.md 참고.
