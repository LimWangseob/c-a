========================================================
  VID 출처 변경 — 라이브 검증 안내 (사무실 PC)
========================================================

이번 업데이트는 상품 인식번호(VID)를 "상품조회/수정" 자료에서 가져오도록
바꾸고, 옵션별 표 분리·판매상태 경고(판매자배송 포함)를 추가했습니다.
실제 로그인 검증이 필요합니다. 아래 순서대로 하세요.

★ 로그인 2차인증 때문에 사무실 PC 에서 사람이 직접 해야 합니다.
★ 순위 라이브는 깨끗한 IP(핫스팟) 권장. 판매수집 로그인은 사무실에서.


--------------------------------------------------------
0단계. 준비 (꼭!)
--------------------------------------------------------
1) 이 "쿠팡애널리틱스" 폴더를 바탕화면/문서 등 쓰기 가능한 곳에 둡니다
   (Program Files 같은 보호 폴더 금지). Google Chrome 설치 필수.
2) 처음 쓰는 PC면 앱을 한 번 켜서 설정 탭에서 API 키·구글시트 링크·
   서비스계정 키를 입력하고, 관리대장을 불러와 비밀번호를 저장하세요
   (자세히는 "첫실행_설정안내.txt").
3) ★ 결과 마스터 파일 백업 ★
   output 폴더의 "쿠팡데이타분석_통계.xlsx" 를 복사해 따로 보관하세요.
   (이번 변경은 VID 가 이전과 다르면 그 상품의 이전 데이터를 지우고
    새로 시작합니다. 되돌릴 수 없으니 반드시 백업.)


--------------------------------------------------------
1단계. 읽기전용 진단 먼저  (마스터 안 건드림)
--------------------------------------------------------
"쿠팡진단.exe" 를 더블클릭합니다. (검은 콘솔 창 + 로그인 창이 뜹니다)

 - 로그인 창이 화면 중앙에 뜨면, 자동으로 아이디/비번이 입력됩니다.
   2차인증(인증번호)이 뜨면 그 창에서 직접 처리하세요.
 - 로그인되면 그 계정의 "상품조회/수정" 자료를 읽어 콘솔에 출력합니다.
   ※ 결과 파일(마스터)·구글시트는 전혀 건드리지 않습니다.

 콘솔 로그에서 확인할 것:
   [상품조회] vendor-inventory/search ...  → 상품/옵션 개수가 나오는지
   [상품조회] 판매상태 원문→해석: ...       → 판매중/판매중지 값이 맞는지 (중요)
   [vid 출처=상품조회/수정] ...             → 각 상품 옵션과 VID 가 나오는지
   [판매상태] vid N개 판정 — 분포: {...}
   [재고] ...

 다른 계정으로 보고 싶으면 (명령 프롬프트에서):
   쿠팡진단.exe --list        (계정 목록 보기)
   쿠팡진단.exe 계정아이디     (그 계정으로 진단)

 ※ 자동 로그인이 봇 차단(Access Denied)에 걸리면:
   쿠팡진단.exe 계정아이디 --manual   (사람이 직접 타이핑해 로그인)


--------------------------------------------------------
2단계. 이상 없으면 실제 앱 실행  (마스터가 바뀝니다)
--------------------------------------------------------
진단에서 상품·VID·판매상태가 정상으로 나오면, 백업을 확인한 뒤
"쿠팡애널리틱스.exe" 를 실행해 "① 판매수집(반자동)" 을 돌립니다.

 실행 후 결과 파일에서 확인할 것:
  - 옵션이 여러 개인 상품이 옵션별 표로 나뉘는지
    (대표 표 = 등록상품명, 그 아래 "등록상품명 (옵션명)" 표들)
  - 상품 이름칸 2줄에 "VID : ..." 가 보이는지
  - 관리대장에서 판매중지인데 쿠팡은 판매중이면 최신 날짜칸에
    빨간 "판매중" 표시가 뜨는지 (판매자배송 상품도 포함)
  - 관리대장에서 사라진 계정의 시트가 결과에서 삭제되는지
  - VID 가 이전과 다른 상품은 이전 데이터가 지워지고 새로 시작하는지


--------------------------------------------------------
문제가 있으면
--------------------------------------------------------
 - 진단 콘솔의 "판매상태 원문→해석" 줄 값을 그대로 알려주세요
   (쿠팡이 주는 실제 표기와 프로그램 해석이 맞는지 맞추는 데 필요).
 - 로그인 자체가 안 되면 --manual 로 다시 시도.
 - 콘솔 창은 로그를 다 본 뒤 닫으면 됩니다(진단은 아무것도 저장 안 함).
