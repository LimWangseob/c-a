# 구글 시트 연동 1회 설정 가이드 (서비스계정)

프로그램이 **관리대장(입력)을 읽고 결과 구글시트(출력)를 쓰려면** 구글 "서비스계정" 1개가 필요합니다.
아래는 **최초 1회만** 하면 되는 설정입니다(계정 담당자 1명이 하고, JSON 키를 각 PC에 등록).

> 서비스계정 = 사람이 아니라 프로그램이 쓰는 구글 계정. 이메일 주소(`...@....iam.gserviceaccount.com`)가
> 발급되며, **그 이메일에 스프레드시트를 공유**해야 프로그램이 접근할 수 있습니다.

---

## 1. GCP 프로젝트 + Sheets API 사용 설정

1. https://console.cloud.google.com 접속(구글 계정 로그인).
2. 상단 프로젝트 선택 → **새 프로젝트** 만들기(예: `coupang-analytics`). 만든 프로젝트를 선택.
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → "Google Sheets API" 검색 → **사용 설정**.
   - (선택) 결과 시트를 프로그램이 새로 만들 계획이면 "Google Drive API" 도 사용 설정.

## 2. 서비스계정 만들기 + JSON 키 발급

1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → 서비스 계정**.
2. 이름 입력(예: `coupang-sheet-bot`) → 만들고 계속 → (역할은 비워도 됨) → 완료.
3. 만들어진 서비스계정 클릭 → **키 탭 → 키 추가 → 새 키 만들기 → JSON** → 다운로드.
   - 이 JSON 파일이 **비밀 키**입니다. **git·공유 폴더·메일에 올리지 마세요.**
4. 서비스계정 이메일을 복사해 둡니다(형태: `coupang-sheet-bot@<프로젝트>.iam.gserviceaccount.com`).
   - 프로그램 **설정 탭에서 JSON을 등록하면 이 이메일이 표시**됩니다.

## 3. 대상 스프레드시트를 서비스계정에 공유

- **관리대장(입력, 「토탈셀러_셀독 관리 대장」)**: 우상단 **공유** → 위 서비스계정 이메일 추가.
  - 읽기만 하면 되므로 **뷰어**로 충분. (비번 평문이 들어있으니 대장은 '링크가 있는 모든 사용자'를 끄고
    서비스계정과 담당자에게만 공유하는 것을 권장합니다.)
- **결과 구글시트(출력)**: **공유** → 위 서비스계정 이메일을 **편집자**로 추가(프로그램이 써야 하므로).

## 4. 프로그램에 등록 (각 PC 1회)

프로그램 **설정 탭**에서:
1. **서비스계정 키(JSON) 등록** — 2번에서 받은 JSON 파일을 선택(또는 내용 붙여넣기).
   - 키는 이 PC 전용으로 **DPAPI 암호화**되어 저장됩니다(`%LOCALAPPDATA%\coupang-analytics\creds.json`).
     원본 JSON 파일은 등록 후 안전한 곳에 보관하거나 삭제하세요.
2. **관리대장(입력) 구글시트 링크 등록** → 옆의 **연결 확인**으로 접근 가능 여부 확인.
3. **결과(출력) 구글시트 링크 등록** → **연결 확인**.

> 다른 PC에서도 쓰려면 그 PC에서 **같은 JSON 파일로 4-1을 다시** 하면 됩니다(DPAPI는 PC/사용자별 암호화라
> creds.json 을 복사해도 다른 PC에선 복호화되지 않습니다 — 각 PC에서 재등록).

---

## 문제 해결

- **403 권한 없음**: 3번(스프레드시트를 서비스계정 이메일에 공유)을 안 했거나, Sheets API 미사용 설정.
- **404 없음**: 링크/ID 오타. 스프레드시트 URL 전체를 붙여넣어도 됩니다(프로그램이 ID를 추출).
- **429 쿼터 초과**: 짧은 시간에 요청이 많음. 프로그램은 요청을 batch로 묶지만, 반복 실행은 잠시 간격을 두세요.
