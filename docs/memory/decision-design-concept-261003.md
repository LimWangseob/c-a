**결정(소유자 2026-10-03, "이런 스타일로 디자인 컨셉을 잡자. 확정.")**: 첫 참고 이미지(쇼핑몰 관리 대시보드, 보라 강조)의 스타일을 앱 전체 디자인 컨셉으로 확정. **색 = 보라**(색 고민 종료).

요소: 밝은 회색 바탕 + 흰 카드(둥근 모서리·얇은 테두리·아주 옅은 그림자) · 강조색은 보라 하나(선택·주 버튼·그래프), 경고만 빨강/주황 · 왼쪽 흰 사이드바(작은 회색 섹션 제목 + 아이콘 + 메뉴 + 숫자 배지 + 아래 사용자) · 상단 경로+큰 제목+오른쪽 기간 알약 버튼(선택=보라 채움)+마지막 수집·새로고침 · 큰 굵은 숫자+비교 배지(▲12%) · 둥근 알약 막대(연한 트랙, 선택 막대만 진하게+말풍선) · 목록은 상태 색 점+굵은 이름+회색 보조+오른쪽 숫자 · 보라 알약 주 버튼.

**Why:** 소유자가 같은 이미지를 처음(2026-10-02)과 확정 때 두 번 제시.
**How to apply:** 시안·앱 화면 모두 이 컨셉. 그대로 베끼지 않고 원칙만(우리 데이터·업무에 맞춤). Qt 적용 시 QSS 로 둥근 모서리·색, 그림자는 성능 위해 테두리 위주. 시안 캔버스 '디자인 컨셉 확정' 보드가 기준.

**✅앱 적용(2026-10-06)**: 통합앱(`ui/app_integrated.py`)에 `ui/theme_qt.py`(QSS 토큰)로 적용 — 밝은 회색 바탕·흰 둥근 카드·**흰 사이드바**(선택=옅은 보라+왼쪽 보라 띠)·강조 보라 `#7c3aed`(주 버튼·탭·선택)·경고만 적색. 기존 `app_qt`는 청록 유지(미접촉). 남은 세부=기간 알약·비교 배지(▲12%)·알약 막대 그래프·실데이터 대시보드. 관련=[[business-context-consignment-creditors]]·[[decision-storage-gsheet-4rules]]·[[handoff-session-261006]]
