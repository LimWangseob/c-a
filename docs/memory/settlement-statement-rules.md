계약자별 **셀독 정산서**(엑셀)를 만들 때의 규칙. 한상현(니코에이블)을 샘플로 확정했고, 전 계정은 운용 PC 수집이 끝난 뒤 같은 방식으로 만든다.

- **저장 위치 = `D:\토탈셀러\쿠팡 정산 자료`**(소유자 지시 2026-10-08). 앱 `output\정산\` 에 만들지 말 것. 이 폴더의 `정산_계정목록.txt` 는 비번 포함 → 열지 말 것.
- **원천 = 운용 PC 앱이 수집한 자료만**(소유자가 `output\정산` 의 계정 파일을 zip 으로 가져옴). 직원이 만든 정리본·ZIP 데이터를 원천으로 쓰지 말 것.
- **규칙 = 우리가 확정한 규칙**(직원 시트 규칙 금지): 정산 3층 — ① 쿠팡 실지급(최종지급액)이 정본 → ② 계약 정산은 ①을 입력으로 계약서 제4조 **갑 70 : 을 30**. 7:3 은 **계정 합산이 정본**(상품별은 참고 추정). 판매수익 = 쿠팡 실지급 − 생산원가(쿠폰·수수료·광고·밀크런·물류비는 실지급에 이미 반영). RG 최종 = H−I−J+K+매출조정(D-003)·보상=대표계좌(D-005)·계좌입금(D-006).
- **혼동 금지**: 쿠팡 지급 분할 70%/30%(①층 지급 시점)와 계약 70/30(②층 갑·을 분배)은 **무관**(숫자만 우연히 같음).
- **상품 분류**: 계약서 외 추가 판매 상품 = **계약 대체 상품**(같은 7:3 적용·원가 단가는 확인 필요). **개인상품(예: 히카마)은 정산·비용·계약에서 제외**.
- 대장↔쿠팡 이름·모델코드 차이는 오타로 단정하지 말 것([[product-name-convention-ledger-vs-result]]).

**Why:** 첫 작성 때 직원 정리본을 원천·규칙으로 써서 소유자가 두 번 바로잡음(원천→앱 수집분, 규칙→확정 규칙). **How to apply:** 정산서 요청 시 위 위치·원천·규칙으로 만들고, 앱 자료에 없는 값은 채우지 말고 "미확인/미수집"으로 표시.
