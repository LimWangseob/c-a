## 도구 3종 (tools/, 현 앱 흐름 미접촉·독립)
- `build_operation_template.py` — 빈 틀 생성. `SHEETS` dict(컬럼=`(이름,그룹 id|content|code,옵션,정의)`), `code` 그룹=자동 숨김, 옵션 num/date/link/derived.
- `migrate_to_operation_ledger.py` — 관리대장(109열)+재고현황 → 운영대장 전환초안(DRAFT). 상품코드 발번(`[분류1자][입고YYMM]-[순번3]` G건기식/P공산품/E기타)·**파생열 INDEX/MATCH 수식연동**(사업자명←계정, 상품(물류)명/그로스재고←관리상품, 현재고←재고, 숨김키=상품코드·계정아이디)·**셀잠금**(파생·키=locked, 원본만 unlock, 시트보호)·상품(물류)명 쿠팡 하이퍼링크·날짜 시간제거·8색 계정밴드·`CONTRACTS` 계약서보강(**사업자명 정확일치**, 없으면 신규행 — 부분일치는 빈 사업자명+`"" in key` 오염 버그라 금지). 매칭실패=`매핑검토` 시트.
- `build_result_sample.py` — 파일④ 포맷 샘플(계정목록·통계블록·정산현황, 실데이터 아님).

실행: `python tools/migrate_to_operation_ledger.py [대장.xlsx] [재고.xlsx] [출력.xlsx]`, `python tools/build_result_sample.py [출력.xlsx]`.
입력 기본경로=`~/Downloads/토탈셀러_셀독 관리 대장 (7).xlsx`·`~/Downloads/재고 현황 (1).xlsx`.
전환 규모(실측): 계정41·관리상품84·재고580·그로스48·체험단21·업무일지426·계약42·매핑검토35.
⚠ 출력 파일이 Excel에 열려 있으면 PermissionError → 새 이름(타임스탬프)으로 생성.
