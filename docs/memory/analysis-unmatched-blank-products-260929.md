**증상**: 결과파일에서 일부 상품만 VID·판매정보·상품링크·로켓그로스·판매상태가 공란(키워드·순위는 채워짐). 원인=그 상품이 `product_match` **미매칭(vid없음)** → vid로 조회하는 지표가 전부 공란(키워드·순위는 상품명 폴백이라 채워져 "일부만 처리"로 보임). 계기=사용자 output(10) 니코에이블 차량용청소기 ST6645. 로그 `[계정 …] 대장 N → 추적 N(매칭 X·vid X) · 미매칭(vid없음) …` 이 대상 표기.

## 미매칭 3원인 (실측·`src/coupang_analytics/product_match.py`)
- **① 중복 한글접두 + 문자시작 모델코드** ★가장 많음★: 매칭 핵심어에서 `_CODE_TAIL`(`[A-Za-z]{1,5}-?\d{2,}…`)이 모델코드(ST6645)를 통째로 제거 → 핵심어가 한글접두 하나만 남음. 그 접두를 가진 발견상품이 2개+(차량용청소기 ST6645 vs Q808) → 마진 0<0.15(애매). 규격 타이브레이커 `_SPEC=^\d+…`는 **숫자시작만** 인정 → 문자시작 코드는 못 가름 → 미매칭. (R601·CHMM01은 한글명이 유일해 정상.)
- **② 괄호를 노출제목으로 오인**: `core_text = _paren(lp.name) or lp.name`(108줄)이 괄호 안을 핵심어로 씀. 담당자가 `신형타프 R008 (블랙)`·`문어발선풍기m10 (대체요망)`처럼 색상·메모를 괄호로 적으면 핵심어가 '블랙'/'대체요망'이 돼 발견제목에 없어 미매칭. (발견 1개인데도 미매칭.)
- **③ 상품조회에 아예 없음**: 대장명↔쿠팡명 상이·판매중지 등 → 발견 0개(목견인기·접이식 정리함 JK0026). 코드론 한계.
