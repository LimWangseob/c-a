**타협 불가한 업무 목표(사용자 재확인)**: **상품×키워드마다 정확한 노출순위(N위)를 매일 확보**. 목적 = 마케팅 전후 순위 변동 추적(예: 마케팅 전 35위 → 후 9위, 하락도). 사용자 생업의 핵심 산출물. **"노출됐다/안됐다" 같은 근사신호로는 대체 불가** — 정확한 등수여야 변동을 잰다. [[rank-antiblock-circuit-breaker]]

**사용자가 명시적으로 거부한 제안 2건(재제안 금지)**:
1. ⛔ **키워드 중복제거(1검색 다상품)** — 상품마다 검색어가 거의 안 겹쳐 절감 효과 없음.
2. ⛔ **Wing 오가닉검색노출(traffic-insight) 보조** — 노출 여부만 줄 뿐 **정확한 등수가 아님** → 마케팅 효과(등수 변동) 측정 불가. [[wing-keyword-data-subscription-gated]]

**제약(왜 어려운가)**: 정확한 등수는 오직 공개검색 결과페이지(`/np/search?q=…`)에만 존재 → Akamai가 정확히 지키는 표면 → 차단. 가벼운 API 대체 불가(자동완성은 검색어 문자열만 주고 순위 없음). 사용자는 **검색 횟수 줄이기(키워드 축소·중복제거·격일)도 거부** → "전체를 매일, 정확히" 해야 함. 원칙 = "검색을 덜 한다"가 아니라 **"같은 총량을 차단 없이 소화"**.

**✅ 채택된 해법 = ③ 반자동 순위조회**([[semi-auto-rank-and-exposed-name]]): 앱이 신뢰 세션 창에서 키워드 자동입력+Enter, 화면만 읽어 정확 등수(최대 300위) 기록. 밤샘 무인 운용 가능(라이브 검증 2026-09-14: 271키워드·차단 0). 차단 시 쿨다운-재개. **IP 로테이션(핫스팟)** 병행이 남은 안전판. 관련 [[login-block-session-first-circuit-breaker]].
