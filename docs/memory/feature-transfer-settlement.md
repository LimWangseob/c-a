미정산 계약자 중 셀독 전환자(①셀독진행 52·②계정수령_상품미등록 51)의 쿠팡 정산금을 미정산 원금에서 공제하려는 기능(소유자 2026-10-22·'셀독 전환자 파일 분석' 세션이 요청 이관). 결과는 미정산 원장(D:\토탈셀러\미정산\·세션 '토탈셀러 계약자 미정산 관리')에 통합 예정.

- **야간 이어 하기(R48·D-112)**: `transfer-login --retry --start 21:00` · 17:40~20:40 시작 안 함 · 차단·미완료·오류 2연속 중단 · 재시도 = 같은 틀린 비번·인증번호·성공 제외(지문). 10-22 결과: 28계정 중 비번오류 14·인증번호 9(비번 맞음·연락 필요)·성공 3.
- **1단계 구현(R47)**: 앱 '셀독전환 정산' 탭 → `정산다운로드.exe transfer-login [--retry]` → `transfer_login.run`. 결과 = `output/정산_셀독전환/로그인확인_*.xlsx`('로그인 결과'·'연락 필요'). 비번 = 파일 먼저 → 관리대장 저장 값(빈 칸 = 관리대장). 원장 정산(D-103)·output/정산 과 분리.
- **2단계 소유자 요구(전달)**: 2026-01-01~ · 계정의 **모든 상품**(구분은 나중에 사람이 — 상품명·옵션·노출상품ID/VID 원본 칸 남김·관리 상품 필터 금지) · 이미 받은 건 다시 안 받음 · 별도 누적 파일.
- ⚠ **빈도 충돌 미해결**: 이 세션 질문 답 = '한 번 다 받고 주 1회' vs 전달된 원문 = '매일 18시 이후'. 2단계 전에 소유자 확인.
