쿠팡 윙 로그인 2차 인증(인증번호)은 **위치·환경 기반 조건부(step-up)**다.
- **사무실(평소 신뢰 환경)**: 2차 인증 없이 ID/비번만으로 통과 → 로그인 테스트는 **사무실에서만 가능**.
- **집 등 낯선 환경/네트워크**: 쿠팡이 **2차 인증(인증번호) 요구** → 자동입력만으로 미완료.

**의미:** unipang이 xauth 폼에 머문 원인 후보 중 "2차 인증"은 *환경 의존*이었음. 소급 확정은 불가(창 닫힘)하나, 확정 테스트는 반드시 사무실에서 `python ui/app.py` 실행으로. 사무실에선 OTP가 안 뜰 가능성이 높아 그때 `[로그인감지]` 로그/스냅샷이 진짜 원인(비번오류/봇차단 등)을 가려줌.

**주의:** 인증번호 5회 오류 시 계정 잠김 → 집에서 반복 로그인 시도 금지. 자동 재시도도 금지(so `wait_for_login`의 error 즉시중단 로직 유지). 관련 진단: [[respond-in-korean]] 규칙대로 한글 로그.

**2차인증 시 대기 없이 건너뜀(2026-09-20 소유자)**: 배치(전체실행/무인)에서 2차 인증(인증번호) 화면이 뜨면 **타임아웃 대기 없이 즉시 그 계정 건너뛰고 다음 계정 진행**(그 계정은 미완료→다음 실행 재시도). `wait_for_login(skip_on_otp=True)`가 `classify_login=='otp'`(입력칸 `_OTP_SELECTORS`) 즉시 False 반환+**로그 남김**('2차 인증 필요 — 대기하지 않고 이 계정 건너뜀'), `_login_and_discover`가 계정명 포함 로그+반자동 재시도도 건너뜀(otp_seen 가드). skip_on_otp 미지정이면 기존대로 안내 후 대기(사람 직접 인증 경로 보존).

**예외(2026-09-04):** 집에서도 **본인 소유 계정 1개 + 열린 창에서 사람이 직접 2FA(수동 로그인, 자동 재시도 없음)** 면 테스트 가능. 금지는 ①위탁(제3자) 계정 ②자동입력·자동제출(Access Denied 유발) ③반복 시도. 캡처/수동 테스트는 `--manual` 로 자동입력 건너뛰고 사람이 타이핑.
