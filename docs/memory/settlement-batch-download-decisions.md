- **돈의 방향 확정(소유자 2026-10-06)**: 쿠팡 정산금은 **쿠팡 → 사업자(계약자) 계좌로 직접 입금**. 우리(커머스 판로)는
  계약서상 사업자에게 줄 금액에서 **사업자 계좌에 이미 입금된 쿠팡 정산금만큼 공제하고 나머지를 지급**. ⇒ ②계약 정산의
  핵심 입력 = 계정별 쿠팡 **실지급 누적**(정산현황 최종지급액·지급일 기준). 약정 총액 정의(계약금만/계약금+수익 등)·
  초과 입금 처리·우리 기지급 기록은 소유자 확인 대기.
- 노출순위 프로그램과 같은 PC 동시 실행 검토 결과: 조건부 가능 — 정산 쪽은 reap_orphan_chrome(데이터폴더 자동화 Chrome 전부 종료) 호출 금지·①판매수집과 같은 계정 프로필 동시 사용 금지(계정 잠금)·창 숨김. IP는 proxy/enabled=true 일 때만 분리.
