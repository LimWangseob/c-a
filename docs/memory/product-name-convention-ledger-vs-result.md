**오래전 확정된 정의(소유자 2026-09-23 재확인·기억 지시):**
- **관리대장(입력)** = **담당자가 알아볼 수 있는 상품명**(짧은 담당자용 이름).
- **결과파일(출력: 통계 시트·계정목록)** = **쿠팡에 등록된 노출 상품명**(길고 서술적인 실제 노출명).

**Why:** 담당자는 대장에서 자기 상품을 알아봐야 하고, 결과는 쿠팡 실제 노출명으로 봐야 함(현장 대조).

**How to apply:**
- 결과 계정목록/통계의 **긴 서술형 이름 = 정상**(노출명). "짧은 대장명과 다르다"는 이유로 **낡았다/틀렸다고 판단 금지**.
- 대장↔쿠팡 매칭은 이름이 100% 일치 안 하므로 정밀 매칭([[input-ledger-format]] 계열)으로 함.
- ⚠ 2026-09-23 A(계정목록 링크) 진단 때 이걸 몰라 "라이브가 옛 이름이라 낡았다"고 오판함 → **결과=노출명이 규약**. 계정목록 재작성/키 대조 시 결과의 노출명을 담당자명으로 갈아엎지 말 것.
