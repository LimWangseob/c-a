사용자는 **쉬운 일상 한국어**를 원한다. 군사·전문 용어를 싫어함 — 예: "재무장"(X) → "감시 다시 걸기"(O), **"배선"(X, 2026-09-16 지적) → "연결/반영/코드에 적용"(O)**. 이런 종류의 용어 전반을 피할 것.

**Why**: 불필요한 조어·jargon은 읽기 불편하고 거슬림.
**How to apply**: 기능·동작을 평범한 말로 설명. 멋부린 조어·군사은유·영어약어 남발 금지. [[respond-in-korean.md]]
