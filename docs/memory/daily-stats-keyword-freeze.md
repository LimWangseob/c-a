전체실행은 **매일 정해진 시간에 1회** 돌리는 시계열 통계다. 통계로서 의미가 있으려면
**한번 시작한 키워드를 종료까지 동결**해야 한다(날마다 재선정하면 순위 추세 비교 불가).

**Why:** 쿠팡 검색결과·후보가 매일 변해 재선정하면 키워드가 달라짐 → 어제/오늘 순위를 같은 축으로 못 봄.

**How to apply (구현됨 2026-09-07):**
- 단일 마스터 `output/쿠팡데이타분석_통계.xlsx`에 매일 **날짜 컬럼만 누적**(+그날 스냅샷 `_통계_yymmdd.xlsx`).
- 둘째날부터 `run_full(carry_forward=True)`: 마스터 로드 → **기존 키워드 동결** → 오늘 컬럼만 채움.
- 새 상품(마스터에 없음)은 그날 첫날처럼 선정. **기존 키워드는 어떤 경우도 제거 금지**.
- 발굴 추가는 **옵션(`grow_keywords=True`)**일 때만: 상한 `KW_MAX_TRACK=10`(2026-09-20 7→10·가변), 하루 `KW_ADD_PER_DAY=2`개 새 키워드만 추가(첫날 `KW_TRACK_N=4`).
- UI 팝업: 진행중(크래시)=이어서/처음부터 · 마스터 있음=기존통계 추가/새 통계(기존 보관)/취소 · 첫 실행=새 통계.
- `카ry`/`grow`는 `진행중.json`에 저장돼 같은 날 크래시 복구 시 모드 유지.

**키워드 출처 이원화(2026-09-13)**: 동결 규칙("값 있으면 재선정 안 함")은 **직원이 결과 통계 시트에 직접 입력한
키워드**에도 적용. 실행 시작 시 `pipeline._pull_gsheet_keywords`가 통계시트 키워드를 워크북으로 역머지 → 그 상품은
AI 선정 생략(동결). 상세=[[gsheet-unified-spec]].

**키워드 = 구글시트 셀 값 기준(2026-09-20 최종 확정 — "이력 보존 안 함"으로 단순화, 중단방식 폐기)**:
결과 구글시트에 **채워진 키워드 셀 값이 곧 추적 대상**. `merge_staff_keywords`가 실행 시작 시 워크북을 시트에 맞춘다 —
**추가**(상품당 상한 `KW_MAX_TRACK=10`·가변), **삭제=행 비움**(`workbook.clear_keyword_row`: 이름·검색량·**과거 순위값까지
삭제**·이력 보존 안 함). 키워드 있으면 **그대로 동결(AI 톱업 없음)** — 4개 중 2개만 있으면 2개만·빈칸 공란 유지.
**키워드 0개(새 상품)만 AI 첫 선정**, `grow`(발굴추가 옵션)일 때만 상한 내 발굴. 검색량 공란만 네이버로 채움. 안전장치:
시트 키워드 0개로 읽히면(파싱실패) 그 상품 미변경. 로컬 마스터는 계속 SSOT(숨김 메타 보존, 구글시트 통째 교체 안 함).
⭐실측: 실제 시트에 담당자 편집 2건 대기(휴라엘 거북목교정기·캠핑타프) → 다음 실행이 반영(옛 키워드·이력 삭제). SSOT=DESIGN §0-0000000.
