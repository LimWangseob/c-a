모든 응답과 산출물(설명·로그·주석 등)을 **한글로 일원화**한다. 영어 단어를 불필요하게 섞지 말 것(코드 식별자 등 불가피한 것 제외).

**Why:** 사용자가 명시적으로 "언어는 한글도 일원화 해줘"라고 요청. 비개발자 담당자도 읽는 프로젝트라 일관된 한글이 가독성에 유리.
**How to apply:** 답변·요약·진단 메시지·문서를 한글로 작성. CLAUDE.md의 "응답 한국어" 지침과 동일 맥락.
