세션이 길어져 판단력이 흐려질 조짐이 보이면, 사용자가 시키기 전에 **먼저 한 줄 권고**를 낸다.
예: "⚠ 세션이 길어져 판단이 흐려질 수 있습니다. 새 세션(/clear)으로 이어가길 권합니다 — 이어가려면 CLAUDE.md·HANDOFF.md·메모리를 읽으면 맥락이 복원됩니다."

**흐려짐 조짐(트리거 신호):**
- 컨텍스트 자동 요약(compaction)이 일어난 뒤.
- 한 세션에서 성격이 다른 대형 작업이 여러 번 누적됨(예: 로그인 디버깅 → 구조 변경 → 클린업 → 실증 …).
- 같은 실수를 반복하거나, 앞서 정한 결정/사실을 잊는 조짐.
- 대화가 매우 길어져 초반 맥락 참조가 흐려질 때.

**Why:** 사용자가 "계속 쓰다 보면 판단이 흐려진다"며 그때 자동 권고를 요청. 긴 세션은 품질 저하로 이어지고, 이 프로젝트는 CLAUDE.md·HANDOFF.md·메모리에 맥락이 잘 정리돼 있어 **새 세션으로 갈아타도 손실이 적다**.
**How to apply:** 다음 큰 작업을 시작하기 전에 위 권고 한 줄을 먼저 제시(작업을 막지는 말고 선택은 사용자에게). 결정/사실이 헷갈리면 추측하지 말고 문서·메모리를 다시 확인. 관련: [[respond-in-korean]].

**한계(정직):** 하네스 훅으로 '판단 흐려짐'을 자동 감지하는 것은 정밀하지 않다(토큰·턴 수 같은 근사치만 가능). 그래서 이 규칙은 Claude 자신의 자각에 의존한다. 근사 지표 기반 리마인더 훅이 필요하면 settings.json 에 별도 설정해야 한다.
