계약자 정산은 **쿠팡 실지급(정산서 최종 지급액)을 계약 조건으로 나눈다. 판매분 원가는 계산하지 않는다.** 등록 상품은 관리대장 기준(계약 상품별로 팔리지 않음). SSOT = `docs/DECISIONS.md` D-152.

- 장대익 = 갑 70 : 을 30 · 서달원 = 아기수영장 7:3, 헬스매트 9:1, 나머지 = DW커머스(계약금+약 30% = 18,200,000 달성 시 종료, 그전 회사 몫 없음)
- 연다인 = 원금 대비 20% 보장(25,085,280)·회사 수익 없음·2026년 5월 이후 등록 상품만·쿠팡 화재 보상금 8,697,763 수익 포함
- 최종 파일 = `D:\토탈셀러\쿠팡 정산 자료\계약자별_정산표_연다인_장대익_서달원_20261103기준_최종_화재보상포함.xlsx`
- 재생성 = `D:\토탈셀러\쿠팡 정산 자료\계약자별_정산표_스크립트\`(`build2.py`, 연다인 범위 재계산 `run_may.py`)

**Why:** 소유자가 2026-11-04 대화에서 계약서 제4조 식(원가 공제)·계약금 회수 방식을 대신해 직접 지시.
**How to apply:** 세 계약자 정산 갱신 시 이 규칙을 쓴다. 다른 계약자 적용 여부는 미정이라 묻는다. `D:\modusign` D-019·D-020(원가 공제)과 다르다는 점을 함께 알린다. 추정분이 있어 D-146·D-148 판단이 남아 있다([[settlement-statement-rules]]).
