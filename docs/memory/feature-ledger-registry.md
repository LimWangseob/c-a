**셀독등록원장** = 매일 바뀌는 셀독관리대장(취소선·줄삭제로 과거 소실)과 별도로 **지우지 않고 쌓는** 구글시트 원장.
월/분기/반기 정산·매출 산정과 과거(대장에서 빠진) 계정 로그인용. SSOT=`designs/LEDGER_REGISTRY.md`.

소유자 확정(2026-09-28):
- 시트 5개: 셀독원장·계정이력·상품이력·**그로스이력**·동기화기록. 그로스 재고=원장 최신값만·이력 제외.
- 대장 삭제/취소선 → 관리상태 '관리중단'+중단일(줄 보존). 사람 확인 단계 없음(삭제는 자동).
- **비밀번호 원문 저장·이력(Claude의 '변경됨+지문' 제안 불수용)** — 원장 파일 한정 예외, 로그·결과시트엔 금지.
- 쿠팡확인·쿠팡확인일 열(대장만 바뀌고 쿠팡 미반영 구분). 비밀번호 불일치=**A안**(자동 재시도 없음·앱 [이전 비밀번호로 1회 시도] 버튼).
- 향후 앱 실행 기준=원장(단계적 전환).

1단계 구현(커밋 완료 2026-09-28): `registry_*.py` 7모듈·`tools/registry_sync.py`·`tools/registry_backfill.py`·
`tools/verify_registry_offline.py`(16시나리오·run_checks 8번째). 관리상태는 **이력에서 계산**(이력=진실원천).

**Why:** 소유자가 판매현황 기간 집계(34계정 엑셀) 후 정산 탭 요구 → 과거 계정·이력 없이는 기간 산정 불가.
**소급 구축 완료(2026-09-28)**: 원장 `셀독등록원장_자동화용`(URL=설정 registry/url)에 사본 24개(09/20~)+현재 대장 재생 → 28계정·84줄·이력131. 이후 매일 반영=`tools/registry_sync.py`. 형식 차이(쉼표·날짜) 정규화 버그 실측 수정.
