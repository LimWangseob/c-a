사람이 시트에 승인/반려를 넣어야 진행되는 대기열(확인필요·보류)을 만들지 말 것. 앱이 근거(글자 규칙 → 쿠팡 데이터(VID 등) → AI)로 판단해 자동 진행하고, 판단 근거를 이력·로그에 남긴다. 판단 불가(AI 장애 등)일 때만 잠시 보류하고 다음 실행에서 자동 재판단.

**Why:** 2026-10-16 원장 상품명 변경 '확인필요' #92·#105 가 9-30부터 16일간 방치돼 쿠팡확인이 매일 누락. 소유자 "AI가 판단해서 보정하고 자동 진행 — 내가 승인과 보류를 인지하지 못해"(D-070).

**How to apply:** 새 기능에서 "담당자 확인 후 반영" 흐름을 떠올리면 자동 판단 + 근거 기록으로 바꾸고, 정말 사람이 필요하면(비번 수정·휴대폰 인증 등) 결과 시트·실행 요약처럼 소유자가 실제로 보는 곳에 사유를 띄운다. 관련: [[feature-ledger-registry]] · [[verify-by-data-not-status]]

**추가(2026-11-05·D-157):** 관리대장 상품명을 코드별로 나눠 달라고 담당자에게 요청하지 말 것. 소유자 "상품명은 AI로 판정하기로 했어. 직원이 명확하게 하지 않는 경우가 있음." 불명확한 이름은 쿠팡 상품명까지 넣어 AI 가 판정하고, 규칙은 후보만 낸다(모델번호 규칙이 드라이기거치대 Y003 에 안전화 Y003 재고를 붙인 실제 사례).
