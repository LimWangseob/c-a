- **회사명 = 커머스 판로**(2026-10-03 확정, 앱 화면 이름도 회사명). **셀독 = 자사 브랜드**(셀독관리 사업).
- **사업 4종 + 추가 가능**: 셀독관리 · 위탁관리(고객 판매처 계정 상품 관리 대행) · 광고 대행 · 상품위탁 판매. 사업 꼬리표는 **상품 단위**(한 계정에 셀독·위탁 상품이 섞임). 셀독을 고객 계정에서 팔면 **계정 주인 몫 = 판매액 일정 비율**(확정). 다른 사업 수익식은 미확인.
- **판매처**: v1 = 쿠팡 우선 · 스마트스토어 준비중(API 보류) · 토스쇼핑·G마켓·당근은 소유자가 확대 예정이라 함(수집 방법 미정). 주문·배송·클레임 = 샵마인([[app-scope-no-orders-shopmine]]), 문의(CS)=D10 범위 안.
- **회사 수익 = 판매 수익 일부** → 정산 핵심(판매처 지급 → 계약 정산 회사 몫/계약자 몫 → 채권자 상환, 정산 3층).
- **특이점**: 파산 직전 — **미지급 정산 투자자 약 370명·300억 원 이상**을 회사 수익 일부로 지속 상환.
- **필요 기능(소유자 열거)**: 계정별 상품관리·체험단/광고·수익률·정산/판매/매출·상품 추천/분석·계약자 CS+고객 CS·통계·재고/사입 등록·회사 창고 입고 실시간 추적·직원 로그인/권한·반출/반품 역흐름·외부 자료(네이버·쿠팡·아이템스카우트)·AI는 보조(결정은 사람)·통계를 계정별/상품별 구글시트 DB화.
- 화면 설계·메뉴(v3.3)·시안 진행 상태 = [[handoff-design-mockup-261006]] (이 메모엔 사업 전제만 둠).
