현행 = D-410(저장소 docs/DECISIONS.md) · D-229. 소유자 원문(2026-11-25): "정산 관련이면 계약자별 건별상품으로 처리하지 말고 일반화 해서 적용해야 함, 특정 상품은 제외라고 코딩하면 안됨. 그래서 확인 요청한것은 적절하지 않음."

**Why:** Q808·그린라이트·터치펜·미니선풍기·스타떡볶이를 소유자에게 물었으나 관리대장·판정표로 알 수 있는 내용이었음.
**How to apply:** 상품 포함 여부는 대장(지금·옛)·원장·계약·쿠팡 등록 자료로 먼저 판정하고, 질문은 규칙 자체가 안 정해졌을 때만 한다. 관련: [[feedback-settlement-decision-delegation]]
