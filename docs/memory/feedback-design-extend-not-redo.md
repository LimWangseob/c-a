"홈화면에 지금 앱 기능을 적용해줘" 요청에 홈을 새로 짰더니 소유자가 "다시 짜면 안됨, 이전에 만든 홈 시안에 앱의 기능이 들어가야 함"이라고 정정함.

**Why:** 소유자는 확정해 가는 시안을 단계적으로 다듬는 중이라, 통째 교체는 이미 합의한 구성(카드·그래프·표)을 잃게 함.

**How to apply:** 시안·화면에 무엇을 "적용/반영/추가"하라면 기존 구성은 그대로 두고 그 안에 섹션·열·버튼을 더한다. 공간이 모자라면 기존 것을 지우지 말고 줄 수·여백을 줄여 맞춘다. 새로 짜는 게 낫다고 보이면 먼저 물어본다. 관련=[[decision-design-concept-261003]]·[[business-context-consignment-creditors]]
