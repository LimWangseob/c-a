### 0-1. 우리 업무에 바로 쓰는 결론 (요약)
1. **통장 입금 ≠ 정산현황 한 곳**: 입금은 ① 윙 정산(주/월정산·최종액·추가지급) ② 로켓그로스 월렛 인출 ③ **우대수수료 환급(쿠팡페이, 매월 ≈17일·≈2일)** ④ 재고 손실 보상(월 단위, CFS 비용과 상계 후) 네 갈래 — 대사 때 4개 메뉴를 모두 봐야 한다(§1-6·1-7·1-9·10-4).
2. **차감은 정산현황에 다 안 보인다**: 광고비(윙 지급에서 상계·로켓그로스는 월 단위)·판매자서비스이용료(월 5만+VAT)·밀크런·CFS 비용·정산차감(최종액/월정산 때만)·보류 → 각 메뉴 엑셀이 증빙(§1-2·1-8·1-9·1-10).
3. **증빙 = 쿠팡에서 내려받은 원본**: 메뉴별 받는 방식(즉시 엑셀 / 요청형 / 미리보기 / 화면만)은 §1-8·1-9 표. 월렛 내역·매입세금계산서 목록은 엑셀이 없어 **화면 인쇄(PDF)** 가 원본.
4. **구매자 개인정보가 든 원본은 암호화 보관**(압축 비밀번호 등·화면 캡처 금지·배송 목적 외 사용 금지) — §2.
5. **노출상품명은 쿠팡이 바꿀 수 있다**(상품명 정책·카탈로그·브랜드 정책) → 결과 파일은 현행 노출명을 VID로 추적(D-015)이 맞다(§9-1·12-4).
6. 2차 인증은 2026-03-19부터 **SMS만** — 위탁계정 로그인 운영에 영향(§11).

## 1. 정산 (도움말 분류 48 · 13개 글 + 로켓그로스 정산 관련 4개 글)

### 1-1. 정산 원칙 (FAQ 132 정산정책)
- 매출 인식 = **구매확정** 기준. 구매확정 = 배송완료 후 7일(주말·공휴일 포함) 자동 / 고객이 직접 확정하면 즉시 / 교환은 교환완료일 + 7일(교환완료가 자동확정일 전이면 최초 배송완료 + 7일).
- 지급액 = 매출 − 판매수수료 − 공제금액(판매자서비스이용료·정산차감·전주채권) + 보류 해제액. 모든 날짜는 **영업일**(지급일이 휴무면 다음 영업일).
- 정산유형은 판매자 단위(상품별로 다르게 못 함). 변경은 **익월 1일 매출분부터**(WING > 판매자정보 > 추가판매정보).
- **주정산**: 월~일 1주 구매확정분의 (매출 − 판매수수료)×**70%** → 그 주 마지막 날 + **15영업일**. 나머지 **30% = 최종액**(반품·취소 대비 유치) → 한 달치 합산해 **익익월 첫 영업일** 지급.
- **월정산**: 1일~말일 구매확정분 **100%** → 말일 + **15영업일**.
- **추가지급**(쿠팡·고객 귀책 손실 보전, 쿠팡확인요청 승인분) → 승인 후 **다음 주 5영업일(차주 금요일)** 지급. 추가지급 주문은 매출내역·지급내역에 안 나오고 **추가지급 메뉴에만** 나옴.
- 고객문의 관련 별도 협의 정산금 = 15일 또는 말일에 추가지급.

### 1-2. 차감 항목 (FAQ 237 정산차감)
- **판매수수료**: 실제 분류된 카테고리 기준(쿠팡이 카테고리 옮기면 바뀐 수수료). 배송비에는 **3%(VAT 별도)**. 할인쿠폰 적용 후 최종가 기준.
- **보류액**: 계좌오류·폐업·고객불만 등 → WING > 정산 > **보류목록**. 해제되면 다음 지급에 합산.
- **판매자서비스이용료**: 배송비 제외 **월 매출 100만 원 이상이면 월 1회 5만 원(VAT 별도 = 55,000원)**. 가전/컴퓨터/디지털은 500만 원 이상일 때.
- **정산차감**: 쿠팡이 고객에게 직접 환불·보상(수기환불·수기보상) 등 → **최종액정산·월정산 때만** 공제(주정산엔 미반영). 매출내역에서 정산차감액 클릭 시 상세.
- **전주채권**: 주차별로 생긴 환불 등 마이너스 금액 이월.
- 광고비: 윙 지급에서 상계(정산현황 '차감 사유'에 '상품/브랜드광고비'로 표시 — 실측). 로켓그로스 광고비는 **월 단위로 다음 달 정산금에서 차감**, 모자라면 다음 정산으로 이월.

### 1-3. 보류 (FAQ 238)
- 사유: 계좌오류/이체오류(예금주≠대표자, 휴면·정지·해지·압류 계좌), 서비스불가(정책 위반·부도), 법원·건보공단 압류, 기타. 자료 제출 시 가장 가까운 지급일에 보류액 지급.
- 보류목록 화면 보류구분: 기타·계약서미비·계좌오류·업체 휴/폐업·서비스 불가·고객 클레임·법적이슈·채권압류·계좌 미등록·이체 오류·고객정보 확인 미이행·해외정산액 미달.

### 1-4. 지급일·캘린더 (FAQ 240)
- WING > 정산 > 정산현황 > **정산캘린더** — 날짜 선택 시 그날 지급내역. 주정산 70% = 주 일요일 + 15영업일, 30% = 매월 말일자 기준 익익월 1영업일.

### 1-5. 세금계산서·부가세 (FAQ 106·107·344)
- WING > 정산 > **매입 세금계산서**: 쿠팡이 판매자에게 발행(판매수수료 + 판매자서비스이용료). **해당 월 매출 기준 익월 5영업일 이내** 발행, 대표 담당자 이메일·홈택스로도 확인.
- 로켓그로스 세금계산서 2종: ① 로켓그로스 판매수수료(쿠팡 주식회사) ② 풀필먼트·물류(CFS) 비용.
- 로켓그로스 광고비 = 월말 계산 → 매입세금계산서 1건.
- **매출(위수탁) 세금계산서**: 위수탁 판매분(해당 계정만).
- 부가세 신고: 매출내역의 판매금액 총계 = 판매자 매출 총액(VAT 포함). 메뉴 **부가세 신고내역**(결제수단별 매출: 신용/체크카드·현금영수증·기타) — 탭 2개: **[중개] 구매확정 기준**, **[로켓그로스] 결제완료 기준**, 월별 **상세 다운로드**. 2015-07 이전 자료 없음. 티켓: 로컬=사용기준, 여행·문화=판매기준.

### 1-6. 우대수수료 환급 (로켓그로스 정산현황 FAQ 333 §5 + 화면)
- 신용카드 우대수수료 정책(2019-01-31~): 카드사가 우대율 초과분을 가맹점(판매자)에 환급.

- **판매자서비스이용료 차감 시점**: 월정산 = 월정산 지급 때, **주정산 = 최종액(30%) 지급 때**. 일반 + 가전/디지털을 함께 팔아 둘 다 기준을 넘어도 **월 5만 원(VAT 별도) 한 번만**. 매출 집계에 배송비 제외(24).

- 매출내역: 화면 엑셀 + '상세 다운로드 > 엑셀 다운로드 요청' = 주문별 상세. 배송비 정산 상세도 상세 다운로드에 있음(104).
- 지급 후 취소 완료된 건은 **다음 주정산에서 차감**. 송장을 다시 올려도 최초 배송완료 시점 기준으로 한 번만 정산(104).

- 배송비 수수료 3%(VAT 별도)·카테고리 수수료는 쿠팡이 분류한 카테고리 기준(130). 정산유형 변경 = 판매자정보 > 추가판매정보에서 직접, 익월 1일 매출분부터(241).

## 2. 주문/배송 (분류 46 · 16개 글)

### 9-4. 아이템위너·노출

- 취소: 결제완료 = 즉시취소, 상품준비중 = 출고중지 요청(24시간 내 미승인 시 쿠팡이 취소), 배송중 = 반품 절차. 배송지연 시 7일 내 고객 요청이면 쿠팡 직권 취소.
- 반품: 접수 1영업일 내 회수지시·송장 등록, 2영업일 내 회수, 입고 후 72시간(영업일) 내 반품승인. 반품배송비 = 귀책 주체 부담(고객: 변심 / 판매자: 결함·상이·지연 / 쿠팡: 시스템 장애). 박스 훼손만으로 반품 거절 불가. 분리배송 반품비는 판매자 부담.
- **쿠팡확인요청**(판매자 손실): 반품진행 상태 입고 = 입고 후 72시간(영업일) 내, 반품완료 상태 입고 = 168시간 내, 미입고·해외반품지 = 반품접수 14영업일 내 온라인 문의. 반려 시 168시간 내 재접수. 승인되면 **추가 정산**(⇒ §1 추가지급).
- 쿠팡은 위반 의심 시 **정산대금 지급을 일시 보류**할 수 있음(제14조②) ⇒ 보류목록 원인.
- 정책 외 고객보상 = 상품가 10% 원칙. 하자·불량 고객 안내 콜비용 건당 5,000원 → 정산 차감(부족하면 판매자가 입금). 소명 못 하면 상품가 100% 고객 보상을 정산에서 공제.
- 패널티: 직권취소·노출중단·판매중단·자격정지, 판매중단 3회 이상 → 계약 해지 가능.

### 12-3. 판매자 관리 정책 (327~332)
- 판매자점수 등급(우수/주의/경고): 정시출고 98/85, 정시배송 95/75, 주문이행 98/85, 24시간 답변 95/50. 경고 지속 → 노출 정지.
- 상품 관리: 품절취소 일정 수준 이상 → 상품 판매정지(재고 증빙+재고 업데이트로 재개) / 불량 사유 교환·반품 2회 → 옵션ID 노출정지 / 가격 오기재 취소 → 노출 정지(3회부터 소명) / 유통기한 경과·불명확 → 1회 상품, 2회 이상 전체 정지 / **중복상품 1·2차 신규등록 제한 1주, 3차 전체 노출정지 1주**.
- 배송 관리: 장기미출고(발주서 미다운·송장 미업로드) 노출정지, 업체직송·해외배송(Unipass 이력·PCCC 요구)·배송방법·가송장·착불배송 어뷰징(해외배송 어뷰징 4회 이상 = 영구정지).
- 택배비: 과다 배송비/반품비(택배사 공시 운임 대비) 수정 요청 → 미수정 시 노출 정지. 안내 비용과 실제 요구 비용이 다르면 상품 판매정지.
- 응대: 무성의·동일 답변 → 2주 모니터링 후 전체 정지 / 고객센터 이관 문의 무의미 답변 1차 경고~4차 1개월 / 24시간 무응답 3차부터 정지 5일 / 불필요 연락(반품비 요구·평점 삭제 요청 등) 2차부터 정지, 고객 주소 방문 연락 2차 영구정지 / 취소·반품 사유를 고객 귀책으로 바꾸는 행위 관리.

## 13. 빠르게 해결하기 (분류 106) · 마이샵 (분류 56)
- 카테고리는 판매자가 직접 못 바꿈 → 온라인 문의. 쿠팡이 옮겨도 바뀐 수수료로 정산되지 않을 수 있어 올바른 카테고리로 **새로 등록** 권장.
- 무료노출 프로모션 반려 사유: 과도한 저가·정상가 과다·배송비 포함가 불일치·번들/증정 구성·랜덤 발송 안내 미흡·**출고소요 2일 초과**·쿠폰 적용 중. 예산 월 100만 원 이상, 신청 후 가격·배송비·재고 수정 시 조기 종료.
- 마이샵: 판매자당 1개. **외부(SNS)에서 마이샵 URL로 들어와 24시간 내 구매하면 판매수수료 0% + 마이샵 운용료 3.5%**(쿠팡 안에서 복사한 URL·다른 광고 링크 경유·판매자배송 아님은 제외) ⇒ 정산서에서 수수료율이 낮게 보이는 주문의 원인 후보.
