# COUPANG_SETTLEMENT_DOMAIN — 쿠팡 정산·매출·판매 도메인 명세

> 목적: 코드 구현 입력용 도메인 지식. 코드 아님. 모듈 설계서 작성 시 이 문서를 근거로 인용.
> 근거: 실계정 화면(2026-09), 쿠팡 다운로드 파일, 헬로안녕 xlsb 2종 역분석. 추정 항목은 `[미확인]` 표기.
> 검증 벡터: `coupang_golden_cases.json` (모든 규칙은 이 케이스 100% 통과가 완료 조건)

## 1. 용어·기준일

| 용어 | 정의 |
|---|---|
| 채널 | `MARKETPLACE`(윙 판매자배송) / `ROCKET_GROWTH`(로켓그로스) — 같은 등록상품ID 안에 옵션별로 공존 가능 |
| 매출인식일(윙) | 구매확정일 |

| 자동구매확정 | 배송완료일 + 7 달력일(주말·공휴일 포함). 고객 수동확정 시 즉시 |
| 교환 | 교환완료 + 7일. 단 자동확정일 전 교환완료면 최초 배송완료 기준 |
| 정산 주 | 월~일. 주가 월 경계를 넘으면 월별로 행 분할(지급일은 동일) |
| 영업일 | 토·일·한국 공휴일·대체공휴일 제외 |

- 70/30 금액: 행 단위 반올림 후 합산(xlsb 동작). 쿠팡 실지급과 원 단위 차이 가능 → 실지급은 API/파일 값이 정본, 계산값은 예측용.

### 2.1 공휴일 (POLICY `HOLIDAY_KR`)
- 하드코딩 금지. 외부 소스(한국천문연구원 특일정보 API, data.go.kr) 연 단위 캐시 + 임시공휴일 수동 추가 경로.
- 대체공휴일 규칙: 국경일(삼일절·광복절·개천절·한글날)·어린이날·성탄절·부처님오신날 = 토·일 겹침 시 대체 / 설·추석 = 일요일(또는 다른 공휴일) 겹침만 대체, 토요일 겹침은 대체 없음.
- 실측 근거: 2026-08-15(토) → 08-17 대체 적용 / 2026 추석 09-24~26(목~토) → 09-28 영업일.
- 공휴일 소스 조회 실패 시 지급일 계산 ERROR raise (0일 가정 금지 — xlsb의 "평일공휴일 수동입력 0" 결함 재현 금지).

## 3. 금액 식

### 3.1 윙 매출내역(중개 매출·구매확정)
```
정산대상액 E = 매출금액 A − 판매자할인쿠폰 B(즉시할인 + 다운로드) − 판매수수료 C − 마이샵수수료 D
최종지급예정액 = E − 정산차감 F
```
- 판매수수료는 쿠폰 차감 후 금액 기준(실측 실효율 ≈ 9.9%, VAT 포함). 카테고리별 요율은 데이터에서 읽을 것(하드코딩 금지).

### 3.2 로켓그로스 실지급
```
실지급 = 판매수수료리포트.정산대상액 − 밀크런 이용액 − 광고비 − CFS 요금
```
- 밀크런·광고비·CFS는 판매수수료 리포트에 없음 → 별도 리포트(광고비 내역 / 밀크런 내역 / 입출고·배송요금 / 창고요금 / 재고손실보상) 조인 필수.

### 3.3 로켓그로스 홈 "이익" (VAT 포함)
```
이익 = 매출 − (판매자할인쿠폰 + 판매수수료 + 풀필먼트서비스비 + 광고비 + 리뷰이벤트) + 재고손실보상
```
- 상품원가 미포함 → 앱의 순이익은 이 값 − 원가 − 외부비용으로 별도 산출.

## 5. 파싱 규칙 (POLICY `PARSE_COUPANG_XLSX`)
- 판매분석 파일은 모든 셀이 텍스트(숫자·`"7.55%"`). 숫자 변환 실패 = ERROR (silent 0 금지).
- 옵션ID(11자리)·등록상품ID·주문번호는 문자열 유지(float 변환 시 정밀도 손실).
- 판매분석 파일 내부에 기간 정보 없음 → 수집 시 `period_start/period_end/account_id`를 메타로 강제 저장. 메타 없는 파일 적재 거부.
- 헤더 기반 매핑(열 위치 의존 금지). 필수 헤더 누락 = ERROR + 누락 목록 로그.
- 엑셀 날짜 시리얼(1899-12-30 기준) / 문자열 날짜 모두 처리.

## 6. 판매분석 파일 검증된 관계 (불변식)
```
매출 = 총매출 + 총취소금액(음수)
판매량 = 총판매수 + 총취소상품수(음수)
구매전환율 = 주문 ÷ 조회 × 100   (방문자 아님)
주문(건) ≠ 판매량(개)
```
- 이전 기간 판매분이 이번 기간 취소되면 매출·주문·전환율 음수 가능 → 정상 데이터, 필터링 금지.
- 매출은 쿠폰 차감 전 → 정산액·이익과 직접 비교 금지. 옵션ID로 정산 데이터와 조인.
- 불변식 위반 행 = WARNING + 행 로그(쿠팡 포맷 변경 감지용).

## 7. 알려진 함정 (재현 금지)
1. 70%·30% 행 동시 수집 → 매출 2중 집계.
2. 공휴일 0일 가정 → 지급일 오차(2023-12 사례: 12/25·1/1 영업일 처리).
3. 피벗 위치 의존 요약식(`MAX(N6:N1000)`) → 레이아웃 변경 시 0 표시. 집계는 DB 쿼리로.
4. 미구매확정 데이터 누락 → 결제일 기준 월 집계는 익월 중순 이후 확정. 화면에 "미확정 구간" 표시 필요.
5. 로켓그로스 부가 차감(밀크런·광고·CFS) 누락 → 이익 과대.

## 8. 운영위탁 계약 모듈 입력 요구 (계약서 수령 후 확정)
- 계정별: 계약금(금액·VAT·납부일·분할·반환조건), 수수료(요율/정액 + 산정 기준: 매출/정산대상액/실지급/순이익 중 택1), 약정이익금(정액/정률, 월/전체, 미달 시 보전·연장·소멸), 계약기간 + 기간 귀속 기준일(결제일/구매확정일/지급일 중 택1), 비용 부담 주체(원가·광고·쿠폰·CFS·밀크런·반품), 분배 주기·지급일, 세금계산서 주체.
- 산출: 계정별 누적 실지급 vs (계약금 + 약정이익금) 달성률·잔액·예상 달성일(지급 예정분 포함).
